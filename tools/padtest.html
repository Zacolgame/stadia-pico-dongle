Pico 手柄测试台（padtest）

需要 Chrome / Edge 桌面版（Web Serial + Gamepad API）。单文件、零依赖、完全离线； file:// 直接双击打开即可用（Chrome 把 file:// 视为安全上下文，Web Serial 可用）。 串口需点击下方按钮授权（用户手势）；手柄需按任意键后浏览器才会列出。 若你的浏览器版本在 file:// 下拦截串口：在本目录运行 python -m http.server 8000 后访问 http://localhost:8000/tools/padtest.html。
